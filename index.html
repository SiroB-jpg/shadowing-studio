Import and export

Already have these sentences and only want their chapter names? Use Update chapter names inside the import screen — it reads the titles without adding anything.

Tidying up

If a corpus file was imported twice, every sentence appears twice and playback speaks both. This finds them and keeps one of each — including the harder case, where two files numbered their groups differently and the same sentence is filed twice under two different group numbers. That one shows up as a chapter with twice as many groups as it should have.

Danger zone

Deletes every sentence, bookmark and cached recording on this device. There is no undo.
